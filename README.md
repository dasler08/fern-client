Fern Client
a little companion app for Path of Titans. maps, quest routes and a map overlay you can keep open while you play

Download the latest version

<img width="1267" height="365" alt="image" src="https://github.com/user-attachments/assets/703d6032-614b-4bcd-af14-f84a6489b3d9" />

what it does
Play button that opens the Alderon Games Launcher for you
Maps for Gondwa, Panjura and Riparia with over 21,000 resource spots, waystones, home caves and place names. you can drop your own pins too
Quest run, you tell it what your quest needs (like 3 turtle shells and 2 berries), click where you are and it plans the shortest way to grab everything. hit Got it when you collect one and it moves you on to the next
Map overlay that sits on top of the game and lets your clicks go straight through it. unlock it with a hotkey to move, resize and zoom it how you like
Hotkeys to show or hide Fern, the overlay and overlay move mode without leaving the game
Sound cues and small on screen notices so you know when something got turned on or off
Themes, Forest Green, Pitch Black, Navy Blue, Soft Pink and Slate Grey

download
go to Releases and grab one of these

Setup installs it normally with a start menu shortcut and an uninstaller. use this one if your not sure
Portable no install, just put it somewhere and run it
works on Windows 10 and 11 (64 bit)

windows might show a blue "Windows protected your PC" screen the first time because the app isnt signed yet. click More info and then Run anyway

default hotkeys
show or hide Fern	Ctrl + Shift + F
map overlay on / off	Ctrl + Shift + M
move and zoom the overlay	Ctrl + Shift + K
you can change all of them in Settings. the overlay needs the game in windowed or borderless mode, fullscreen draws over everything

is this a cheat?
no. Fern runs on its own next to the game, it doesnt read, inject into or change Path of Titans in any way. it just shows maps and info you could find on the web anyway, built to stay inside the Path of Titans terms of service

building it yourself
you need Node.js and Rust

npm install
npx tauri build
the installer ends up in src-tauri/target/release/bundle/nsis
